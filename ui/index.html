Яндекс Музыка запускается во встроенном плеере внизу Главной: выберите трек, перейдите на Главную и нажмите ▶. VK воспроизводится там же после импорта сессии. Если встроенный поток Яндекса недоступен, откройте трек в приложении сервиса. Если поток VK недоступен, откройте трек на странице VK.

Подключение

Токен сервиса хранится в %APPDATA%\music-controller и не уходит никуда, кроме API этого сервиса.
