# Astra Music

Музыкальный плагин для [Astra](https://github.com/mihailinl/AstraPlugins) от **Voltur**. Поиск и воспроизведение музыки из Яндекс Музыки и VK, управление голосом, плеер в Astra и отдельный виджет Windows.

[Скачать последнюю версию](https://github.com/Voltur792/astra-music/releases/latest)

❗❗❗ Важно: Для использования всех функций плагина, необходимо скачать Source code (zip), распаковать, далее в Разработке Загрузить плагин через Обзор

## Возможности

- Поиск песен, исполнителей и личных плейлистов в Яндекс Музыке и VK.
- Воспроизведение плейлистов, «Моей волны» Яндекс Музыки и всех личных треков VK по порядку.
- Пауза, продолжение, переключение треков, перемотка и громкость от 0 до 10.
- Голосовое управление через Astra; точные команды можно связать с действиями плагина.
- Плеер с обложкой, очередью и анимацией, реагирующей на звук.
- Отдельный перемещаемый виджет Windows с прозрачностью, сохранением положения и режимом поверх окон.
- Четырнадцать вариантов цветомузыки для виджета и фона Astra, с регулировкой интенсивности. Можно выбрать только музыку плеера, все звуки ПК или выключить эффект.
- Музыка для будильников и таймеров в [Sleep Pause Timer](https://github.com/Voltur792/SPT).
- Трансляция музыки в Discord через [Voice communication-Discord](https://github.com/Voltur792/VC-Discord), с отдельной очередью и громкостью.

## Подключение музыки

1. Скачайте `.astraplugin` из [Releases](https://github.com/Voltur792/astra-music/releases/latest) и импортируйте в Astra.
2. Откройте вкладку **Музыка**. Для Яндекс Музыки введите токен аккаунта Музыки; для VK нажмите кнопку входа в карточке сервиса.
3. Найдите песню или плейлист и нажмите **Играть в Astra**.
4. Для всей библиотеки VK нажмите **Включить мои треки ВК**; для персональной подборки Яндекса — **Включить «Мою волну»**.

Подключения сохраняются на компьютере и переживают перезапуск. Если сервис отзовёт сессию, войдите повторно. Кнопка отключения VK удаляет сохранённый вход.

В Windows для встроенного плеера нужен Microsoft Edge. Музыка продолжает играть при переключении вкладок и сворачивании виджета. Плагин работает, пока запущена Astra.

## Виджет и цветомузыка

Откройте **Музыка → Виджет на рабочем столе** и включите **Показывать на рабочем столе**. Перетаскивайте карточку за название песни. Можно настроить показ поверх окон и прозрачность от 0 до 80%; положение и настройки сохраняются.

Крестик закрывает виджет, не останавливая музыку. Кнопка **Вернуть виджет на экран** помогает после смены мониторов.

Цветомузыка включается отдельно для виджета и фона Astra. Выберите визуализацию, источник звука и интенсивность. В режиме **Только музыка** эффект прекращается на паузе; **Все звуки** реагирует на звук компьютера. По умолчанию фон выключен.

## Голосовое управление

Команды можно произносить Astra или писать в её чате:

| Задача | Пример |
| --- | --- |
| Включить песню | «Включи песню Кино Группа крови» |
| Найти музыку | «Найди музыку группы Кино» |
| Плейлист | «Включи плейлист Любимое» |
| Персональная подборка | «Включи мою волну» |
| Библиотека VK | «Включи мою музыку в ВК» |
| Пауза / продолжение | «Пауза музыки» / «Продолжи музыку» |
| Переключение | «Следующий трек» / «Предыдущий трек» |
| Перемотка | «Перемотай на 1:20» |
| Громкость | «Громкость музыки 5», «Сделай музыку тише», «Сделай музыку громче» |
| Остановка | «Останови музыку» |

Для управления без запроса к модели привяжите фразы к действиям плагина в редакторе команд Astra. Готовые привязки устанавливаются скриптом [install-local-voice-commands.ps1](scripts/install-local-voice-commands.ps1); после установки полностью перезапустите Astra. Распознавание речи использует выбранный в Astra источник.

## Музыка для таймеров

В [Sleep Pause Timer](https://github.com/Voltur792/SPT) версии 1.1.0 и новее нажмите **Музыка из Astra Music** в будильнике или выберите музыкальное действие таймера. Можно найти песню или взять текущую.

Оба плагина должны быть включены, а музыкальный сервис — подключён в Astra Music. Для интеграций с локальными действиями загрузите обновлённые исходники плагинов через **Plugins → Dev** и перезапустите их.

## Музыка в Discord

1. Включите Astra Music и [Voice communication-Discord](https://github.com/Voltur792/VC-Discord), затем подключите бота к голосовому каналу.
2. Откройте **VC-Discord → Музыка** и выберите песню, плейлист, «Мою волну» или «Мои треки VK».
3. Управляйте воспроизведением и громкостью во вкладке Discord-плагина или голосом: «Астра, следующий трек», «Астра, громкость 5».

Музыка, выбранная в VC-Discord, звучит только в голосовом канале. Её очередь, пауза и громкость управляются отдельно от плеера на компьютере. Во время ответа бота музыка становится тише. Управлять ею голосом могут разрешённые в VC-Discord аккаунты.

Для трансляции нужен установленный FFmpeg. Подключения музыкальных сервисов настраиваются в Astra Music. После обновления перезапустите оба плагина.
