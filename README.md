# Astra Music

Музыкальный плагин для Astra: ищет и запускает музыку из Яндекс Музыки и VK, управляет очередью и показывает плеер на главной странице.

## Возможности

- Поиск треков и личных плейлистов в Яндекс Музыке и VK.
- Воспроизведение в виджете Astra, пауза, перемотка, громкость, следующий и предыдущий трек.
- Запуск плейлистов и «Моей волны» Яндекс Музыки.
- Голосовые инструменты Astra и локальные точные команды для управления плеером без запроса к языковой модели.
- Виджет с обложкой и анимацией, которая подстраивается под звук, если Astra предоставляет аудиоданные.

## Что потребуется

Плагин поставляется как исходный код для Astra. Для запуска нужен Python 3.10 или новее и зависимости из `requirements.txt`. Astra не включает Python в свою установку. Если Python отсутствует, Astra сообщит об этом и предложит установить runtime; библиотеки Python следует установить в тот интерпретатор, которым запускается плагин:

```powershell
python -m pip install -r requirements.txt
```

Для VK дополнительно нужен Node.js с npm и подключение к интернету: при первом использовании VK плагин подготавливает EasyVK. Runtime Node.js указан в манифесте Astra, чтобы она могла сообщить, если он отсутствует. Вход в VK и Яндекс выполняется отдельно во вкладке плагина; нужна активная учётная запись, а для Яндекс Музыки — доступ к сервису.

Точные команды «пауза», «играй», «следующий трек», «предыдущий трек» и «громкость 1–10» настраиваются скриптом `scripts/install-local-voice-commands.ps1`. Эти действия не расходуют токены языковой модели; распознавание речи зависит от выбранного в Astra распознавателя.

## Подключение музыки

1. Откройте вкладку **Музыка** в Astra.
2. Подключите Яндекс Музыку токеном аккаунта Музыки либо войдите в VK через кнопку в карточке VK.
3. Найдите трек или плейлист и запустите его кнопкой **Играть в Astra**.

Токены и сессия VK хранятся локально в каталоге данных пользователя Astra. Не отправляйте этот каталог в публичный репозиторий.
