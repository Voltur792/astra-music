# Astra Music

Музыкальный плагин для Astra: ищет и запускает музыку из Яндекс Музыки и VK, управляет очередью и показывает плеер на главной странице.

[Скачать последнюю версию](https://github.com/Voltur792/astra-music/releases/latest)

## Возможности

- Поиск треков и личных плейлистов в Яндекс Музыке и VK.
- Воспроизведение в виджете Astra, пауза, перемотка, громкость, следующий и предыдущий трек.
- Отдельный перемещаемый виджет Windows: включается по желанию, запоминает положение и может отображаться поверх окон. Управляет тем же плеером и использует выбранную цветомузыку.
- Запуск плейлистов и «Моей волны» Яндекс Музыки.
- Воспроизведение всей личной музыки ВК по порядку: кнопка «Включить мои треки ВК» или команда «включи мою музыку в ВК».
- Голосовые инструменты Astra и локальные точные команды для управления плеером без запроса к языковой модели.
- Виджет с обложкой и анимацией, которая подстраивается под звук.
- Цветомузыка: выключена, для всех звуков ПК или только для музыки плеера. В режиме «только музыка» на паузе и при заблокированном воспроизведении эффект выключается.
- Четырнадцать визуализаций: спектр, неоновые волны, жидкий свет, круги на воде, цветные ленты, орбита, частицы, волновая сетка, бинарные волны, ландшафт частиц, шёлк, всплеск, цветной дождь и слоистые контуры. Интенсивность регулируется; виджет и фон Astra включаются отдельно. Настройки сохраняются после перезапуска; по умолчанию фон выключен.
- В Windows звук воспроизводит отдельный постоянный процесс Microsoft Edge без окон. Переходы между вкладками и сворачивание виджетов не останавливают музыку. Виджет только управляет плеером, а фон располагается под интерфейсом Astra.
- Режим «Все звуки» захватывает выход выбранного по умолчанию устройства через WASAPI loopback. Запускать трек плагина для этого не нужно; микрофон не используется.
- Цветомузыка реагирует на громкость, бас и ударные.

## Что потребуется

Плагин поставляется как исходный код для Astra. Для запуска нужен Python 3.10 или новее и зависимости из `requirements.txt`. Astra не включает Python в свою установку. Если Python отсутствует, Astra сообщит об этом и предложит установить runtime; библиотеки Python следует установить в тот интерпретатор, которым запускается плагин:

```powershell
python -m pip install -r requirements.txt
```

Для VK дополнительно нужен Node.js с npm и подключение к интернету: при первом использовании VK плагин подготавливает EasyVK. Runtime Node.js указан в манифесте Astra, чтобы она могла сообщить, если он отсутствует. Вход в VK и Яндекс выполняется отдельно во вкладке плагина; нужна активная учётная запись, а для Яндекс Музыки — доступ к сервису (Яндекс плюс).

Для постоянного аудиоплеера Windows нужен установленный Microsoft Edge. В Linux пока используется прежнее воспроизведение внутри виджета. Зависимости `soundcard` и `numpy` нужны для спектра системного выхода.

Аудиоплеер запускает отдельный профиль Edge без расширений и синхронизации. Если его страница перестаёт отвечать, плагин один раз автоматически перезапускает музыкальный процесс; при повторном сбое кнопка ▶ позволяет повторить запуск.

Точные команды «пауза», «играй», «следующий трек», «предыдущий трек» и «громкость 1–10» настраиваются скриптом `scripts/install-local-voice-commands.ps1`. Эти действия не расходуют токены языковой модели; распознавание речи зависит от выбранного в Astra распознавателя.

## Подключение музыки

1. Скачайте `.astraplugin` из [GitHub Releases](https://github.com/Voltur792/astra-music/releases/latest) и импортируйте его в Astra.
2. Откройте вкладку **Музыка** и подключите Яндекс Музыку токеном аккаунта Музыки либо войдите в VK через кнопку в карточке VK.
3. Найдите трек или плейлист и запустите его кнопкой **Играть в Astra**.

Токены, cookies и постоянный профиль входа VK сохраняются локально и переживают перезапуск ПК. Временная ошибка сети не сбрасывает сохранённый вход. VK может отозвать сессию — в таком случае потребуется повторный вход. Кнопка отключения VK удаляет сохранённую сессию и профиль входа.

Большая библиотека VK загружается в фоне: кнопка показывает подготовку очереди, не ожидая завершения в коротком запросе интерфейса. Команду «включи мою музыку в ВК» можно связать напрямую с действием плагина через `scripts/install-local-voice-commands.ps1 -OnlyVkLibrary`; после установки команды полностью перезапустите Astra.

«Внешний плеер — дополнительные настройки» управляет только кнопкой «Открыть». Для встроенного воспроизведения менять эту настройку не требуется.

Во вкладке **Музыка → Виджет на рабочем столе** включите «Показывать на рабочем столе». Перетащите карточку за название трека в удобное место. Положение, режим «Поверх других окон» и прозрачность 0–80% сохраняются. Чтобы убрать виджет, отключите его в настройках — музыка продолжает играть. Кнопка «Вернуть виджет на экран» сбрасывает положение, например после отключения второго монитора. Виджет работает, пока запущена Astra.

Настольная карточка имеет прозрачные скруглённые углы, таймлайн и кнопки внизу. Цветомузыка в ней усилена на 35%. Голосовые команды отвечают коротким текстом, например «Громкость музыки установлена на 5 из 10».

В режиме «Все звуки» захват автоматически переподключается после временного сбоя или смены устройства вывода. Если устройство долго недоступно, плеер показывает сообщение о повторном подключении; воспроизведение музыки продолжается независимо от захвата.

## Интеграция с Таймером паузы

В плагине «Таймер паузы» версии 1.1.0 и новее можно выбрать трек из Яндекс Музыки или VK для будильника, таймера и действия при бездействии. Оба плагина должны быть запущены в Astra, а выбранный сервис — подключён во вкладке «Музыка».
