# Изменения

## 2.5.0

- Вкладки Astra Music, карточка плеера и встроенная очередь используют оформление Astra UI Kit. Выбор сервиса, переключатели и строки горячих клавиш используют штатные компоненты Astra.
- В светлой теме подложки сохраняют читаемость на тёмных обоях. В тёмной теме карточки стали плотнее. В шапке используется значок плагина, а кнопка поддержки оформлена в общем стиле.
- Переключатели радиоведущей разнесены по строкам. Кнопки частоты и времени остаются на месте при смене выбора. Во время загрузки интерфейса показывается статус.
- Исправлена задержка обычного ввода с клавиатуры во время воспроизведения Яндекс Музыки и VK на Windows ([#5](https://github.com/Voltur792/astra-music/issues/5)).

## 2.4.0

- Вкладка «Радиостанции»: международный каталог Radio Browser, поиск по стране/жанру/названию, страницы результатов, избранное над каталогом и свои ссылки.
- Astra умеет показывать избранные станции и включать их по названию; при нескольких совпадениях уточняет выбор.
- HLS/MP3/AAC-радио в фоновом плеере; локальная передача манифестов, сегментов и ключей без зависимости от CORS станции. Для эфира отключены перемотка, лайк и переключение песен.
- Голосовое создание приватных плейлистов Яндекс Музыки из выбранных треков с проверкой порядка, защитой от повторного создания и сообщением о частичном результате.
- Поиск популярных треков конкретного исполнителя и временная очередь подобранных песен.
- Нативные палитра и пипетка Windows работают без запуска PowerShell.

## 2.0.0

- Очередь воспроизведения раскрывается под виджетом Astra поверх соседних карточек. Выбирайте трек в очереди Яндекса или VK, не меняя размер плеера.
- Отдельная очередь настольного виджета получила значок Музыки; исправлены расположение и показ окна.
- Цвета виджетов и очереди меняются по сервису: Яндекс — жёлтый и чёрный, VK — синий, Spotify — зелёный. В настройках можно выбрать собственные фон и акцент.
- Исправлены фоновая визуализация Astra, анализ прямых MP3 VK и загрузка вкладки при доступе к интерфейсу Astra.
- Локальные Python-клиенты переиспользуют HTTP-соединения; опрос состояния виджета объединён.
- Кнопка «Помощь / поддержка» находится рядом с вкладками и открывает форму обращения на GitHub без ложного сообщения об ошибке.
- Добавлены русские название и описание карточки каталога в `locales/ru.json`.

**Новое разрешение:** `dom_access` нужно для раскрытия очереди внутри интерфейса Astra. При обновлении из каталога Astra предложит подтвердить расширение доступа; до подтверждения новая версия не устанавливается. Без контроллера интерфейса предусмотрено отдельное окно очереди.

Spotify остаётся экспериментальным. Выбор трека из собственной очереди поддерживается для Яндекса и VK; очередь Spotify открывается в самом Spotify. Linux и macOS остаются экспериментальными.
