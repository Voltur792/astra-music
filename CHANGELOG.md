# Изменения

## 2.0.0

- Очередь воспроизведения раскрывается под виджетом Astra поверх соседних карточек. Выбирайте трек в очереди Яндекса или VK, не меняя размер плеера.
- Отдельная очередь настольного виджета получила значок Музыки; исправлены расположение и показ окна.
- Цвета виджетов и очереди меняются по сервису: Яндекс — жёлтый и чёрный, VK — синий, Spotify — зелёный. В настройках можно выбрать собственные фон и акцент.
- Исправлены фоновая визуализация Astra, анализ прямых MP3 VK и загрузка вкладки при доступе к интерфейсу Astra.
- Локальные Python-клиенты переиспользуют HTTP-соединения; опрос состояния виджета объединён.
- Кнопка «Помощь / поддержка» находится рядом с вкладками и открывает форму обращения на GitHub без ложного сообщения об ошибке.
- Добавлены русские название и описание карточки каталога в `locales/ru.json`.

**Новое разрешение:** `dom_access` нужно для раскрытия очереди внутри интерфейса Astra. При обновлении из каталога Astra предложит подтвердить расширение доступа; до подтверждения новая версия не устанавливается. Без контроллера интерфейса предусмотрено отдельное окно очереди.

Spotify остаётся экспериментальным. Выбор трека из собственной очереди поддерживается для Яндекса и VK; очередь Spotify открывается в самом Spotify. Linux и macOS остаются экспериментальными.
